# Mom's Test Studio (iPhone Home Screen PWA)

Public URL: `https://ShaunDataAnalytics.github.io/mom-test-studio/`

## iPhone Installation
1. Open `https://ShaunDataAnalytics.github.io/mom-test-studio/` in **Safari**.
2. Tap **Share** (box with arrow) → **Add to Home Screen**.
3. Launch "Mom's Test" directly from your iPhone home screen!
   - 100% offline via Service Worker & `localStorage`.
   - Never search in Finder again.
